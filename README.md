# ระบบสำรวจข้อมูลการดำเนินงานธนาคารหน่วยกิต (Credit Bank)
### สำนักงานเขตพื้นที่การศึกษาประถมศึกษาน่าน เขต 1 (สพป.น่าน เขต 1) ปีงบประมาณ 2570

🌐 **เว็บไซต์ใช้งานจริง (Production):** [https://nan1-credit-bank70.vercel.app](https://nan1-credit-bank70.vercel.app)  
📦 **GitHub Repository:** [https://github.com/intensityrtt/CreditBank70.git](https://github.com/intensityrtt/CreditBank70.git)  

ระบบเว็บแอปพลิเคชันสำหรับสำรวจ ติดตามความก้าวหน้า และประมวลผลข้อมูลการดำเนินงานระบบธนาคารหน่วยกิต (Credit Bank) ระดับการศึกษาขั้นพื้นฐาน จากโรงเรียนขยายโอกาสทางการศึกษาในสังกัด สพป.น่าน เขต 1 จำนวน **34 โรงเรียน** เพื่อนำข้อมูลไปรายงานต่อสำนักงานคณะกรรมการการศึกษาขั้นพื้นฐาน (สพฐ.)

---

## 🌟 จุดเด่นและคุณสมบัติของระบบ

1. **เข้าใจง่ายที่สุด ไม่ซับซ้อน (Friendly UX สำหรับผู้ใช้อายุ 23–60 ปี)**:
   - ใช้ฟอนต์ตระกูล **Sarabun** ขนาดตัวอักษร 16–18px ชัดเจน สบายตา คอนทราสต์สูง
   - ปุ่มกดขนาดใหญ่ (Touch Target ≥ 48px) รองรับทั้งสมาร์ตโฟน แท็บเล็ต และคอมพิวเตอร์
   - แบ่งขั้นตอนเป็น 6 ขั้นตอน มีแถบความก้าวหน้าร้อยละแบบเรียลไทม์
   - **บันทึกร่างอัตโนมัติ (Autosave Draft)** ในเครื่อง ไม่ต้องกลัวข้อมูลสูญหายเมื่อปิดแท็บหรือเน็ตหลุด
   - เลือกชื่อโรงเรียนจากรายการ ระบบจะเติม **รหัสสถานศึกษา 10 หลัก** และขนาดโรงเรียนให้อัตโนมัติ
   - มีระบบคำนวณผลรวมผู้เรียนสะสมหน่วยกิตสดๆ ทันทีที่กรอกตัวเลข

2. **สกัดแผนภาพอินโฟกราฟิกจาก สพฐ. ฝังในแบบสำรวจโดยตรง**:
   - **ส่วนที่ 2 (5 รูปแบบการเทียบโอน):** ฝังแผนภาพคำอธิบาย 5 รูปแบบการเทียบโอนและระบบธนาคารหน่วยกิต
   - **ส่วนที่ 3 (โครงการขับเคลื่อน):** ฝังแผนภาพ 9 โครงการตามนโยบาย Credit Bank สพฐ.
   - **ระบบ Modal Lightbox:** คลิกที่รูปภาพหรือกดปุ่ม "ดูภาพขยาย" จะเปิดหน้าต่างดูภาพความละเอียดสูงแบบเต็มจอได้ทันทีโดยไม่เปลี่ยนหน้า และข้อมูลที่กรอกไว้ไม่หาย
   - รองรับการโหลดแบบ Instant (Zero-latency) ด้วยการแปลงภาพเป็น Base64 ฝังในโค้ดควบคู่กับไฟล์ภาพจริง

3. **แบ่งแยกสิทธิ์ชัดเจน (Public vs. Admin Security)**:
   - **หน้าสาธารณะ (สำหรับ 34 โรงเรียน):** แสดงเฉพาะแถบ **"แบบสำรวจสำหรับสถานศึกษา"** และ **"ระบบผู้ดูแลเขต (Admin)"** เพื่อป้องกันความสับสนและไม่ให้โรงเรียนเข้าถึงข้อมูลภายใน
   - **ระบบเฉพาะผู้ดูแลเขต (Admin Portal):**
     - ปกป้องด้วยรหัสผ่าน PIN (รหัสเริ่มต้นถูกปิดบัง ไม่แสดงบนหน้าจอเพื่อความลับทางราชการ)
     - มีแถบ **Admin Control Center** เชื่อมต่อไปยัง:
       1. 📊 **ภาพรวม & วิเคราะห์สถิติ (Dashboard):** แสดงกราฟสรุป Chart.js ครบทุกมิติ, ปุ่มเปิด-ปิดรับแบบสำรวจ, ลิงก์ตรงไปยัง Google Sheets และ Google Drive
       2. 📋 **ติดตามความก้าวหน้า 34 รร. (Tracking Board):** ตรวจสอบสถานะการส่งข้อมูลรายโรงเรียน ค้นหา กรองอำเภอ และปุ่มรีเซ็ตข้อมูลรายแห่งกรณีส่งผิด
       3. 📑 **ข้อมูลรายงาน สพฐ. (OBEC Official Report):** สรุปข้อมูลระดับเขตพื้นที่ 1:1 ตรงตามเอกสาร สพฐ.
     - **ระบบ Route Guard:** บล็อกผู้ใช้ทั่วไปไม่ให้เข้าถึงหน้าติดตามหรือรายงาน สพฐ. หากไม่ผ่านการล็อกอิน Admin

4. **ระบบนำข้อมูลไปรายงานต่อ สพฐ. (OBEC Report & 1-Click Copy)**:
   - คำนวณและประมวลผลข้อมูลจาก 34 โรงเรียนแบบเรียลไทม์
   - **ปุ่มคัดลอกคำตอบ 1-Click รายข้อ:** คลิกเดียวเพื่อนำตัวเลขไป Paste วางใน Google Form ของ สพฐ. ได้ทันที ลดเวลาและป้องกันความผิดพลาด
   - **พิมพ์แบบฟอร์มทางการ (Print / PDF A4):** จัดรูปแบบตามมาตรฐานหนังสือราชการ มีช่องลงนามผู้รายงานและ ผอ.สพป.น่าน เขต 1
   - ดาวน์โหลดข้อมูลดิบเป็นไฟล์ CSV สำหรับนำไปวิเคราะห์ต่อใน Excel

## 🚀 ขั้นตอนการติดตั้งและเชื่อมต่อระบบ

### 1. ฝั่งหลังบ้าน (Google Apps Script & Google Sheet)
1. เปิด Google Sheet ฐานข้อมูล:  
   👉 [https://docs.google.com/spreadsheets/d/1OX7wLdznfnRAvR0XkIoKXS7lD8TlWMMsE95thnsuIrU](https://docs.google.com/spreadsheets/d/1OX7wLdznfnRAvR0XkIoKXS7lD8TlWMMsE95thnsuIrU/edit?usp=drive_link)
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. คัดลอกโค้ดจากไฟล์ `google-apps-script/Code.gs` ไปวางแทนที่โค้ดเดิมทั้งหมด แล้วกด **บันทึก (Ctrl + S)**
4. เลือกฟังก์ชัน `setupDatabase` ที่แถบด้านบน แล้วกด **เรียกใช้ (Run)** เพื่อสร้างตารางฐานข้อมูลและบันทึกรายชื่อ 34 โรงเรียนเริ่มต้น
5. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้รายการใหม่ (New deployment)**:
   - ชนิด: **เว็บแอป (Web app)**
   - Execute as: **ฉัน (Me)**
   - Who has access: **ทุกคน (Anyone)** *(สำคัญมาก)*
6. คัดลอก **URL ของเว็บแอป** ที่ได้มาเก็บไว้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)
7. เข้าหน้าเว็บ ฝั่ง **Admin Portal** -> กดปุ่ม **ตั้งค่า API / Web App** แล้วนำ URL มาวางและกดบันทึก
