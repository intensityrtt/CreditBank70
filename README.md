# ระบบสำรวจข้อมูลการดำเนินงานธนาคารหน่วยกิต (Credit Bank)
### สำนักงานเขตพื้นที่การศึกษาประถมศึกษาน่าน เขต 1 (สพป.น่าน เขต 1) ปีงบประมาณ 2570

ระบบเว็บแอปพลิเคชันสำหรับสำรวจ ติดตามความก้าวหน้า และประมวลผลข้อมูลการดำเนินงานระบบธนาคารหน่วยกิต (Credit Bank) ระดับการศึกษาขั้นพื้นฐาน จากโรงเรียนขยายโอกาสทางการศึกษาในสังกัด สพป.น่าน เขต 1 จำนวน **34 โรงเรียน** เพื่อนำข้อมูลไปรายงานต่อสำนักงานคณะกรรมการการศึกษาขั้นพื้นฐาน (สพฐ.)

---

## 🌟 จุดเด่นของระบบ

1. **เข้าใจง่ายที่สุด ไม่ซับซ้อน (Friendly UX for Age 23–60)**:
   - ใช้ฟอนต์ตระกูล **Sarabun** ขนาดตัวอักษร 16–18px อ่านสบายตา คอนทราสต์ชัดเจน
   - ปุ่มกดขนาดใหญ่ (Touch Target ≥ 48px) เหมาะกับทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน
   - แบ่งขั้นตอนเป็น 6 ขั้นตอนย่อย มีแถบความก้าวหน้าชัดเจน
   - มีระบบ **บันทึกร่างอัตโนมัติ (Autosave Draft)** ในเครื่อง ไม่ต้องกลัวข้อมูลหายหากปิดเบราว์เซอร์
   - ป้อนชื่อโรงเรียนจากเมนู Dropdown ระบบจะเติม **รหัสสถานศึกษา 10 หลัก** และขนาดโรงเรียนให้อัตโนมัติ

2. **ตรงตามแบบสำรวจ 2 ฉบับแบบ 1:1**:
   - ข้อคำถามฝั่งโรงเรียนตรงตาม **`รายงาน CreditBank โรงเรียน.pdf`** ทุกข้อ (ส่วนที่ 1 ถึง 6)
   - หน้าจอประมวลผลฝั่งเขตพื้นที่ตรงตาม **`รายงาน CreditBank สพฐ.pdf`** ทุกตาราง

3. **ระบบติดตามความก้าวหน้าแบบเรียลไทม์ (Public Tracker)**:
   - ตรวจสอบสถานะการส่งข้อมูลของโรงเรียนทั้ง 34 แห่ง (✅ ส่งแล้ว / ⏳ ยังไม่ส่ง)
   - แสดงสถิติรวมผู้เรียนสะสมหน่วยกิต และร้อยละความสำเร็จของเขตพื้นที่
   - ค้นหาตามชื่อโรงเรียนและอำเภอได้อย่างรวดเร็ว

4. **ระบบเฉพาะผู้ดูแลระบบ (Admin Portal)**:
   - ล็อกอินด้วยรหัส PIN ปลอดภัย (รหัสเริ่มต้น: `nan1credit2570`)
   - **สวิตช์เปิด / ปิด ระบบรับแบบสำรวจ**: Admin สามารถเปิดหรือปิดรับข้อมูลได้ทันที
   - กราฟสารสนเทศวิเคราะห์ผล (Chart.js) แสดงยอดผู้เรียน 5 รูปแบบ, 9 โครงการ, สถานะขึ้นทะเบียน, MOU, คำของบประมาณ และปัญหาอุปสรรค
   - สั่งรีเซ็ตข้อมูลโรงเรียนรายแห่งกรณีส่งผิดและต้องการแก้ไข

5. **ระบบนำข้อมูลไปรายงานต่อ สพฐ. (OBEC Report & Quick Copy)**:
   - รวบรวมสถิติตามแบบรายงาน สพฐ. อัตโนมัติ
   - **ปุ่ม "คัดลอกค่า" รายข้อ**: คลิกเดียวเพื่อคัดลอกตัวเลขไปวางใน Google Form ของ สพฐ. ได้ทันที ประหยัดเวลา ไม่ต้องกดเครื่องคิดเลข
   - **พิมพ์แบบฟอร์มทางการ (Print / PDF A4)**: จัดรูปแบบตามมาตรฐานหนังสือราชการ มีช่องลงนามผู้รายงานและ ผอ.สพป.น่าน เขต 1
   - ดาวน์โหลดข้อมูลดิบเป็นไฟล์ CSV สำหรับวิเคราะห์เพิ่มเติม

## 🚀 ขั้นตอนการติดตั้งและใช้งาน (3 ขั้นตอนง่ายๆ)

### ขั้นตอนที่ 1: ติดตั้งหลังบ้าน (Google Apps Script & Google Sheet)
1. เปิด Google Sheet ฐานข้อมูล:
   👉 **https://docs.google.com/spreadsheets/d/1OX7wLdznfnRAvR0XkIoKXS7lD8TlWMMsE95thnsuIrU/edit?usp=drive_link**
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. คัดลอกโค้ดจากไฟล์ `google-apps-script/Code.gs` ไปวางแทนที่โค้ดเดิมทั้งหมด แล้วกด **บันทึก (Ctrl + S)**
4. เลือกฟังก์ชัน `setupDatabase` ที่แถบด้านบน แล้วกด **เรียกใช้ (Run)** เพื่อสร้างตารางฐานข้อมูลอัตโนมัติ
5. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ชนิด: **เว็บแอป (Web app)**
   - Execute as: **ฉัน (Me)**
   - Who has access: **ทุกคน (Anyone)** *(สำคัญมาก)*
6. คัดลอก **URL ของเว็บแอป** ที่ได้มาเก็บไว้ (เช่น `https://script.google.com/macros/s/AKfycb.../exec`)

---

### ขั้นตอนที่ 2: นำระบบหน้าบ้านขึ้น GitHub
1. เปิด Terminal ในโฟลเดอร์นี้ แล้วสั่งคำสั่ง:
   ```bash
   git init
   git add .
   git commit -m "Initial Credit Bank Survey System Nan 1"
   git branch -M main
   ```
2. สร้าง Repository ใหม่บน GitHub ของท่าน (เช่น `credit-bank-nan1`)
3. เชื่อมโยงและ Push ขึ้น GitHub:
   ```bash
   git remote add origin https://github.com/ชื่อผู้ใช้ของคุณ/credit-bank-nan1.git
   git push -u origin main
   ```

---

### ขั้นตอนที่ 3: Deploy ขึ้น Vercel
1. เข้าเว็บไซต์ **https://vercel.com** แล้วล็อกอินด้วย GitHub
2. กดปุ่ม **"Add New..."** -> **"Project"**
3. เลือก Repository `credit-bank-nan1` ที่เพิ่ง Push ขึ้นไป
4. ในหน้าตั้งค่าโปรเจกต์:
   - **Framework Preset:** เลือก `Other` หรือ `Vite` (ระบบจะตรวจจับอัตโนมัติ)
   - ไม่ต้องตั้งค่า Build Command หรือ Output Directory เพิ่มเติม
5. กดปุ่ม **"Deploy"**
6. ภายใน 10 วินาที ท่านจะได้ลิงก์เว็บไซต์ใช้งานจริงทันที เช่น `https://credit-bank-nan1.vercel.app`
7. เข้าไปที่เว็บไซต์ของท่าน คลิกไอคอนรูปเฟือง ⚙️ มุมขวาบน แล้วนำ **URL Google Apps Script** จากขั้นตอนที่ 1 มาวาง แล้วกดบันทึก เป็นอันเสร็จสมบูรณ์!
