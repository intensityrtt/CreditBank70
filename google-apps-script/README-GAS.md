# วิธีติดตั้งและเชื่อมต่อ Google Apps Script (Server)

ระบบนี้ใช้ Google Apps Script เป็น Server หลังบ้าน เชื่อมต่อไปยัง Google Spreadsheet:
**https://docs.google.com/spreadsheets/d/1OX7wLdznfnRAvR0XkIoKXS7lD8TlWMMsE95thnsuIrU/edit?usp=drive_link**

---

### ขั้นตอนที่ 1: เปิด Google Apps Script
1. เปิด Google Spreadsheet ข้างต้นในเว็บเบราว์เซอร์
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. ลบโค้ดเดิมทั้งหมดในไฟล์ `Code.gs` แล้วนำโค้ดจากไฟล์ `google-apps-script/Code.gs` ไปวางแทนที่
4. กดบันทึก (Ctrl + S หรือไอคอนแผ่นดิสก์)

---

### ขั้นตอนที่ 2: รันฟังก์ชันสร้างฐานข้อมูล (Setup Database)
1. ที่แถบเครื่องมือด้านบน เลือกฟังก์ชัน `setupDatabase`
2. กดปุ่ม **เรียกใช้ (Run)**
3. ระบบจะขอสิทธิ์เข้าถึง (Authorization Required) ให้กด **ตรวจสอบสิทธิ์ (Review permissions)** -> เลือกบัญชี Google ของท่าน -> กด **ขั้นสูง (Advanced)** -> กด **ไปที่ (ไม่ปลอดภัย) / Go to ... (unsafe)** -> กด **อนุญาต (Allow)**
4. เมื่อรันเสร็จ ระบบจะสร้างตาราง 4 ชีตให้อัตโนมัติ:
   - `Settings`: กำหนดสถานะเปิด/ปิด, ปีงบ 2570, รหัสผ่าน Admin PIN (`nan1credit2570`)
   - `Schools`: บรรจุรายชื่อสถานศึกษาเป้าหมายทั้ง 34 โรงเรียนพร้อมติดตามสถานะ
   - `Submissions`: บันทึกคำตอบและผลสำรวจอย่างละเอียดทุกข้อ
   - `Logs`: บันทึกประวัติการส่งข้อมูลและการสั่งการของผู้ดูแลระบบ

---

### ขั้นตอนที่ 3: เผยแพร่เป็นเว็บแอป (Deploy as Web App)
1. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** มุมขวาบน -> เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกไอคอนรูปเฟือง ⚙️ ด้านซ้าย เลือกประเภท **เว็บแอป (Web app)**
3. กรอกรายละเอียด:
   - **คำอธิบาย (Description):** `Credit Bank Nan 1 API v1`
   - **เรียกใช้ในฐานะ (Execute as):** `ฉัน (Me - บัญชีของท่าน)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(สำคัญมาก! ต้องเลือก Anyone เพื่อให้หน้าเว็บส่งข้อมูลเข้ามาได้โดยไม่ต้องล็อกอินบัญชี Google)*
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL ของเว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`
   ตัวอย่าง: `https://script.google.com/macros/s/AKfycbx.../exec`

---

### ขั้นตอนที่ 4: นำ URL ไปใส่ในระบบหน้าบ้าน
- นำ URL ที่ได้ไปวางในช่องการตั้งค่า หรือไฟล์ `js/config.js` ในตัวแปร `GAS_API_URL`
- ในหน้าเว็บ ระบบจะมีปุ่มตั้งค่าให้ใส่ URL ของ Google Apps Script ได้ทันทีผ่านหน้าต่างการตั้งค่า (Admin Settings) โดยไม่ต้องแก้โค้ดเลย!
